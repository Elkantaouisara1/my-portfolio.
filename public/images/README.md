# Images

- `portrait.jpg` : photo professionnelle (optionnelle). Après ajout, branchez-la dans `src/components/sections/Hero.tsx`.
- Captures de projets : par exemple `windguard.png`. Puis renseignez le champ `screenshot` du projet dans `src/data/projects.ts` :

```ts
screenshot: "/images/windguard.png",
```
